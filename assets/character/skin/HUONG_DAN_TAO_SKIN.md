# ⚡ HƯỚNG DẪN THAY ĐỔI SKIN NHÂN VẬT (1 BƯỚC DUY NHẤT - KHÔNG CẦN SỬA CODE)

Để thay thế nhân vật trong game thành bất kỳ nhân vật mới nào bạn muốn, bạn **KHÔNG CẦN SỬA BẤT KỲ FILE CODE HAY CONFIG NÀO**.

---

## 🚀 CÁCH THAY ĐỔI NHANH NHẤT (CHỈ CẦN DÁN ĐÈ ẢNH):

Chỉ cần mở Photoshop / Procreate / Illustrator / Canva, vẽ nhân vật mới rồi **LƯU / DÁN ĐÈ TRỰC TIẾP** vào thư mục [`assets/character/skin/`](file:///d:/LMHT/Traditional%20game%20MVP/assets/character/skin/):

1. **`body.png`** (Kích thước: `1130 × 1536 px`)
   - Vẽ toàn bộ thân thể nhân vật mới (Đầu, tóc, mũ/khăn, thân áo, váy/quần, 2 chân, cánh tay trái).
   - ⚠️ **LƯU Ý:** **KHÔNG vẽ cánh tay phải** (vì tay phải sẽ do 3 file bên dưới cử động vật lý).

2. **`upper_arm_unified.png`** (Kích thước: `322 × 648 px`)
   - Vẽ phần bắp tay và vai áo bên phải (từ vai áo kéo xuống cùi chỏ).

3. **`forearm.png`** (Kích thước: `69 × 221 px`)
   - Vẽ cẳng tay phải (từ cùi chỏ nối đến cổ tay).

4. **`hand.png`** (Kích thước: `325 × 270 px`)
   - Vẽ bàn tay phải ở tư thế khum tròn cầm dây quả còn.

👉 **Sau khi paste 4 file vào thư mục `assets/character/skin/` -> Bấm F5 trên trình duyệt -> Nhân vật mới hiển thị ngay lập tức!**

---

## 🎨 3 QUY TẮC KHI VẼ ĐỂ KHÔNG BAO GIỜ BỊ LỖI KHỚP:

1. **Giữ nguyên kích thước khung ảnh (Canvas Size)** của từng file (Body: 1130x1536, Upper Arm: 322x648, Forearm: 69x221, Hand: 325x270).
2. **Định dạng file:** Luôn xuất file **PNG nền trong suốt (Transparent)**.
3. **Mẹo vẽ khớp tay:** Mở file ảnh cũ ra, giảm độ mờ (Opacity) xuống 30% làm khung mẫu mờ bên dưới, rồi vẽ nhân vật mới đè lên đúng theo dáng đứng và vị trí vai/tay của ảnh mẫu.
